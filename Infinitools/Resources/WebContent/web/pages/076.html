Como testar seu projeto

Abra index.html, edite o código e toque em Atualizar prévia. CSS, JavaScript e imagens devem estar no projeto, com caminhos relativos. Use Importar ZIP para preservar pastas.

O rascunho mais recente é salvo neste aparelho. Antes de criar ou importar outro projeto, exporte o atual. Apagar os dados ou desinstalar o aplicativo também apaga o rascunho.

Esta ferramenta é um testador local, sem hospedagem nem link público. Exportar ZIP guarda uma cópia na área Arquivos do Infinitools; de lá você pode salvar ou compartilhar.

A prévia é simplificada e tem orçamento de recursos de 8 MiB. Não executa PHP, Python, banco de dados, builds npm ou APIs externas. Projetos React/Vite precisam ser compilados antes; módulos JavaScript e navegação entre páginas podem exigir um servidor de desenvolvimento externo.
