Perguntas frequentes
Como executar código no infiniCompiler?
Escolha a linguagem, escreva o código e clique em Executar. A saída e os erros aparecem no console. A execução depende da API do OneCompiler configurada no servidor.
Quais linguagens estão disponíveis?
A lista é carregada da API do OneCompiler e inclui linguagens como Python, PHP, Java, C, C++, JavaScript e bancos de dados. Opções web ausentes da lista da API são identificadas no catálogo.
O código é enviado para outro serviço?
Sim. Ao clicar em Executar, o código e a entrada padrão são enviados ao OneCompiler pela API. O texto digitado também pode ficar salvo neste navegador para recuperação.
Posso alterar o tema e os atalhos?
Sim. O modo escuro, os atalhos e os recursos visuais podem ser alterados na própria ferramenta. Essas preferências são armazenadas no servidor por IP.
